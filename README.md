# 📐 Math Monopoly Kelas 6

Game edukasi interaktif berbasis web untuk melatih kemampuan matematika siswa kelas 6 SD.

## 🌟 Materi yang Diujikan
- Operasi hitung bilangan bulat
- Luas dan Keliling Lingkaran
- Volume Bangun Ruang (Kubus)
- Statistika dasar (Rata-rata)

## 🕹️ Cara Bermain
1. Klik tombol **Kocok Dadu**.
2. Karakter 🏃 akan berpindah sesuai angka dadu.
3. Jawab pertanyaan yang muncul pada pop-up browser.
4. Jika **Benar**, kamu tetap di petak tersebut.
5. Jika **Salah**, kamu harus mundur 1 langkah!

## 🛠️ Teknologi
- HTML5
- CSS3
- JavaScript (Vanilla)
